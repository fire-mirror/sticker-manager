表情管家 Windows 测试版

开始使用：
1. 双击 Start-StickerManager.cmd，或直接双击 sticker_manager.exe。
2. 首次启动后，程序会常驻 Windows 右下角托盘区域。
3. 默认按 Ctrl+Shift+E 唤出快速选择面板；也可以右键托盘图标打开主管理窗口。

如果 Windows 弹出安全提示，请确认文件来源后选择“仍要运行”。本包是便携版，
不需要管理员权限，也不需要安装程序。程序数据保存在当前 Windows 用户目录中。

卸载：
删除本 ZIP 解压出来的文件即可。程序不会修改 QQ 或微信原始表情文件。

注意：
这是测试版。QQ、QQNT、微信的真实粘贴和发送行为需要在目标设备上自行验证。
